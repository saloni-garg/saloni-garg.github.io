Saloni Garg

I am a machine learning engineer at Adobe, on the Firefly team in San Jose. My day job is GPU systems for generative models: getting big multimodal models trained, post-trained, and served without wasting compute or anyone's patience.

The question I keep coming back to, at work and in my own projects, is a boring sounding one that turns out not to be boring at all: how do you know a model actually got better? A lot of my recent work is verifiers, evaluation, and RL environments, because that is where the honest answer lives.

Before Adobe I spent five years at Wayfair, in Berlin and then the US, building high traffic production systems. I have also written a textbook on retrieval-augmented generation, which still surprises me a little.

02Selected work

Things I built outside the day job. All of it is public, so you do not have to take my word for any of it.

  • gpu-train-debug

    An RL environment that hands a model a broken GPU training run and asks it to find the fault. Built because I kept meeting the same failures at work: OOMs dressed up as loss spikes, misconfigured sharding, silent data bugs. Includes train, hard, test, and out-of-distribution splits, and a full validation run comparing SFT with verifier-based RL.

    Python / Verifiers / Prime Intellect / Hugging Face

  • memfix

    A memory layer for AI agents that keeps receipts. Every fact points back to its source, corrections are append-only, and nothing is silently overwritten. Listed on Glama, submitted to the awesome-mcp-servers list.

    Python / MCP / SQLite or Postgres / MIT

  • jev-max

    A browser agent for the web as it actually is: shadow DOM, iframes, canvas fallbacks, file uploads, drag and drop. Comes with an MCP server and a benchmark suite, because an agent demo without numbers is just a story.

    TypeScript / Playwright / MCP / MIT

  • Contributions

    Open source contributor to Ray and PyTorch, and lately to verifier tooling in the OpenEnv ecosystem. The OpenEnv fix above is the one I would start with if you want to see how I work in someone else's codebase.

    github.com/saloni-garg
