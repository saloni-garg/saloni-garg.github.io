02LLM Evals From Zero

A nine-chapter course on evaluating LLM applications: why demos mislead, how to design an evaluation suite and build the golden dataset it runs on, deterministic and reference-based scoring, LLM-as-a-judge and its calibration, evaluation for RAG pipelines and agents, release gates in CI, and online evaluation and drift in production. 196 slides.

  • Chapter 1: Why Your App Is Already Broken (And Demos Won't Tell You)

    Why "looks good" is not a metric. A support RAG system under test, a prompt change that appears to improve quality, and why manual spot-checks pass while the system is broken.

    View slides

  • Chapter 2: Anatomy of an LLM Evaluation Suite

    What an eval suite actually looks like, and how to design one: evaluation is multi-dimensional, and a single accuracy number can stay flat while quality moves.

    View slides

  • Chapter 3: Building the Golden Dataset

    The input the suite runs on: what a golden dataset actually is, the wrong way to build one, and one case examined field by field.

    View slides

  • Chapter 4: Scoring Without an LLM

    Deterministic and reference-based scoring, implemented: the eval runner, the scorer interface, exact match and token F1, retrieval metrics, and paired comparison against a frozen baseline.

    View slides

  • Chapter 5: LLM-as-a-Judge, Implemented

    A scorer made of a model: judge prompt and rubric design, structured verdicts, evidence-first claim checking, and bias experiments for position, verbosity, and self-preference.

    View slides

  • Chapter 6: Trust, Measured

    Calibrating the LLM judge against blind human labels: confusion matrices, Cohen's kappa, false passes, and per-capability trust decisions (gate, warn only, or human always).

    View slides

  • Chapter 7: Beyond Single Answers

    Stage-wise evaluation for RAG pipelines and multi-step agents: retrieval metrics and failure attribution, trajectory scoring, fault injection, and repeated-run success rates.

    View slides

  • Chapter 8: The Gate

    Evaluation in CI that blocks bad releases: policy as code in gate.yaml, thresholds set from measured baseline noise, a two-tier pipeline, and baseline management.

    View slides

  • Chapter 9: After the Merge

    Online evaluation, drift, and maintenance: production sampling, shadow and canary evaluation, provider fingerprinting, and the eval health dashboard.

    View slides

03vLLM vs SGLang: Production Serving, Measured

A nine-chapter course on serving LLMs in production: one workload (Llama-3.1-70B on 4x H100, with chat and document QA tenants under a fixed SLO contract) measured on both engines, from KV cache capacity math and batching to quantization, scale-out, speculative decoding, and fleet operations. 178 slides.

  • Chapter 1: The Serving Problem, In Numbers

    TTFT, TPOT, goodput versus peak throughput, and KV cache headroom. The request lifecycle priced stage by stage, and the workload and SLO contract the whole course is measured against.

    View slides

  • Chapter 2: Two Engines, Two Architectures

    PagedAttention and block management versus RadixAttention: one request traced through both engines, both scheduler loops, and an architecture diff anchored to source files.

    View slides

  • Chapter 3: The KV Cache Is Your Real Capacity Limit

    Bytes per token derived from the model config, concurrency ceilings per context length, prefix caching economics per tenant, and a working capacity calculator.

    View slides

  • Chapter 4: Batching, Prefill, and the TTFT/TPOT Trade

    Roofline analysis of prefill and decode, long-prompt poisoning, and chunked prefill swept at three chunk sizes on the mixed two-tenant trace, ending in the tuning matrix.

    View slides

  • Chapter 5: Benchmarking Without Lying To Yourself

    Open-loop Poisson replay versus closed-loop inflation, coordinated omission, cache state controlled between runs, and goodput as the headline metric for both engines.

    View slides

  • Chapter 6: Quantization In Production: FP8 and AWQ

    Weights, activations, and KV cache as three separate quantization decisions: quality measured on golden task sets, silent kernel fallbacks, and cost per 1M tokens for every engine and precision cell.

    View slides

  • Chapter 7: Parallelism and Scale-Out

    Tensor, pipeline, and data parallelism compared on the same GPU count, interconnect latency measured rather than assumed, and prefill/decode disaggregation priced per request.

    View slides

  • Chapter 8: Speculative Decoding and Structured Output, Priced

    Acceptance rates measured per tenant slice, break-even curves against batch size, and the per-token cost of grammar-constrained decoding at production concurrency.

    View slides

  • Chapter 9: Running It: SLOs, Autoscaling, Failure

    The metrics that page, the saturation order as load climbs, queue-wait autoscaling with cold-start accounting, failure drills, and the completed cost workbook.

    View slides
